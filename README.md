# Freelancer Marketplace (Mini Upwork)

A web-based platform that connects **clients** with **freelancers**.  
Clients can post projects and freelancers can browse those projects and submit bids based on their skills, proposed cost, and delivery time.

The platform simplifies the hiring process and provides an organized environment for managing freelance work.

---

## Features

### Project Posting
Clients can create and post project listings including:
- Project description
- Budget
- Deadline
- Required skills

### Project Bidding
Freelancers can:
- Browse available projects
- Submit bids with proposed cost
- Provide estimated delivery time

### User Profiles
The platform supports user profiles for both:
- Clients
- Freelancers

Profiles include:
- Skills
- Experience
- Previous work

### Messaging System
Clients and freelancers can communicate directly through the platform to discuss project details.

### Project Management
Clients can:
- Review bids
- Select a freelancer
- Track project progress from start to completion
